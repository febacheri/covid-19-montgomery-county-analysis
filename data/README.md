# Data
This folder contains data used in the COVID-19 analysis project.

## Source
- CDC Open Data Source: COVID-19 Case Surveillance Public Use Data with Geography

## Notes
- Raw data files are not included in this repository due to file size.
- Data can be downloaded from the CDC open data portal.
- Data from CDC open data portal was filtered and downloaded for only Montgomery County, PA cases.
- Cleaned datasets generated by scripts may be saved locally but are not tracked.
